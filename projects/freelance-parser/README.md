# freelance-parser

Мониторит новые заказы на Kwork и FL.ru прямо в терминале. Показывает только новые, старые не повторяет.

## Установка

Зависимостей нет — только стандартная библиотека Python.

```bash
cd freelance-parser
python main.py
```

## Фильтр по ключевым словам

Открой `keywords.txt` и впиши что ищешь — по одному слову на строку:

```
python
бот
парсер
```

Если файл пустой — показывает всё подряд.

## Как работает

- опрашивает Kwork API и FL.ru каждые 5 минут
- новые заказы выводит сразу, уже виденные пропускает
- виденные сохраняет в `seen.json`
- интервал меняется в `main.py` переменная `INTERVAL`

## Структура

```
main.py          — главный цикл, вывод в терминал
parser_kwork.py  — парсер Kwork
parser_fl.py     — парсер FL.ru
storage.py       — сохранение виденных заказов
keywords.txt     — фильтр по словам
```
