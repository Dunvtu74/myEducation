# csv-analyzer

Читает CSV и считает min/max/avg по числовым колонкам. Без pandas — только стандартная библиотека.

```bash
python main.py            # создаст sample.csv и проанализирует его
python main.py myfile.csv # или свой файл
```

Типичное задание на курсах по Python когда проходят работу с файлами.
